- Command: `./build-t001-notest/bin/mllm-restore-benchmark --scenario direct-kv-scaffold --backend host-sim --payload-bytes 4096 --iterations 2 --touch-stride 64`
- Required Env: `cmake >= 3.25`；本次验证使用 `~/.local/bin/cmake 3.31.10`，`x86 dev host` 即可

- Input / Model / Config: 无模型依赖；使用 synthetic payload 做最小 scaffold baseline
